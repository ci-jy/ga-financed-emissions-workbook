# Methodology

## Data sources

Both tables are Statistics Canada open data and need no API key.

| Table | Content | Use |
|---|---|---|
| [38-10-0097-01](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=3810009701) | Physical flow account for greenhouse gas emissions, kt CO2e by industry (IOIC codes), 2009-2023 | Sector emissions, reconciliation, NIR bridge |
| [36-10-0488-01](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=3610048801) | Output by industry, $M current dollars, same IOIC codes, 1997-2022 | Emission-factor denominator, benchmark weights |

`scripts/fetch_statcan.py` downloads both full tables and keeps the Canada rows in `data/raw/`. The rest of the build runs from those committed snapshots.

The GDP-by-industry table 36-10-0402-01 was considered, but it publishes only provinces and territories on NAICS codes. 36-10-0488-01 uses the same seven-character IOIC codes as the emissions account, so no second crosswalk is needed.

## Crosswalk

`data/reference/sector_crosswalk.csv` maps all 124 StatCan IOIC industry codes to 22 portfolio sectors, plus three out-of-scope buckets: government and non-profit, owner-occupied dwellings, and fictive industries. The build fails if StatCan publishes a code the crosswalk does not map.

## Formulas

- Emission factor (tCO2e per $M CAD) = sector emissions (kt x 1000) / sector gross output, for each sector and year 2009-2022, using `SUMIFS` over the raw StatCan tabs. The Inputs tab picks the reporting year (default 2022, the latest year both tables cover).
- PCAF financed emissions (corporate bonds) = attribution factor x issuer revenue x sector EF, where attribution factor = outstanding / EVIC.
- If issuer revenue is on file the holding gets data-quality score 4. If not, revenue = EVIC x the sector revenue/EVIC proxy and the score is 5.
- Carbon footprint = financed emissions / $M invested.
- WACI = sum of portfolio weight x issuer intensity (tCO2e per $M revenue). With sector factors, the issuer intensity equals the sector EF.
- Benchmark = each sector's share of Canadian gross output in the reporting year. The Benchmark Comparison tab shows active weights, contribution differences and an allocation effect, `(w_p - w_b) x (EF - WACI_b)`, which sums to the WACI gap.
- Carbon cost = financed emissions x price x (1 - free-allocation share).

## Carbon-price scenarios

Prices are CAD per tonne. The paths live in `data/reference/carbon_price_scenarios.csv` and can be edited on the Inputs tab.

| Scenario | 2024 | 2026 | 2028 | 2030 | Free allocation |
|---|---:|---:|---:|---:|---:|
| Current federal policy (OBPS benchmark, +$15/t a year) | 80 | 110 | 140 | 170 | 80% |
| Net-zero shadow price (illustrative) | 150 | 200 | 250 | 300 | 50% |
| Delayed transition (illustrative: frozen to 2027, then catch-up) | 80 | 80 | 140 | 260 | 80% |

Only the current-policy path follows the federal schedule. The other two and all free-allocation shares are assumptions.

## Reconciliation

The full report is `reports/reconciliation.md`, generated by `scripts/build_data.py`.

- Industry rows match the published `Total, industries` row within rounding in every year from 2009 to 2023. Each row is rounded to the nearest kt, so the tolerance is half a kt per row (54 to 57.5 kt). The largest gap is 5 kt.
- Industries plus households exceed the National Inventory Report by 28 to 53 Mt a year. The account follows the SNA residence principle (resident carriers' fuel burned abroad counts), while the inventory is territorial. StatCan's published bridge items close the gap to within 3 kt.
- The output table's matched rows cover 100% of published total output in every year.

## Synthetic portfolio

`scripts/make_portfolio.py` is seeded. Issuers are named `SYN <sector> NN Corp`, sector weights come from `data/reference/sector_assumptions.csv`, and 30% of holdings have revenue on file.
